# JavaScript & Vue 강의안

## 강의 성격 요약
이 강의는 **Vue를 깊게 다루는 강의가 아니라**,  
**JavaScript를 구조적으로 다루는 능력을 기르는 강의**이며  
Vue는 프레임워크의 역할을 이해하기 위한 **마지막 맛보기 단계**로 사용한다.

# JavaScript & Vue 강의안

## 강의 성격 요약
이 강의는 **Vue를 깊게 다루는 강의가 아니라**,  
**JavaScript를 구조적으로 다루는 능력을 기르는 강의**이며  
Vue는 프레임워크의 역할을 이해하기 위한 **마지막 맛보기 단계**로 사용한다.

이 강의의 목표는  
**프레임워크 없이도 JavaScript 코드의 실행 흐름과 데이터 흐름을 설명할 수 있는 개발자**를 만드는 것이다.

---

## JavaScript를 배우는 목적
JavaScript를 공부하는 목적은 다음 세 가지다.

- 사용자의 행동에 반응하기 위해서  
- 서버와 데이터를 주고받기 위해서  
- 화면(UI)을 동적으로 제어하기 위해서  

이 강의에서는 문법 암기나 프레임워크 사용법보다  
**코드가 어떤 순서로 실행되고, 데이터가 어떻게 흘러가는지**를 이해하는 데 집중한다.

1. Vue CDN 시작

Vue는 CDN 방식으로도 바로 사용할 수 있다.

실습 5-1

파일명: 5-1-vue-start.html

<!DOCTYPE html>
<html>
<body>

<div id="app">
  <p>{{ message }}</p>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp } = Vue;

  createApp({
    data() {
      return {
        message: "Hello Vue"
      };
    }
  }).mount('#app');
</script>

</body>
</html>

핵심 포인트

  • {{ }} 는 데이터 출력
  • DOM 직접 조작 없음
  • 데이터가 화면에 자동 반영됨

2. 데이터 바인딩 — v-model

v-model은 입력값과 데이터를 양방향으로 연결한다.

실습 5-2

파일명: 5-2-v-model.html

<!DOCTYPE html>
<html>
<body>

<div id="app">
  <input v-model="text">
  <p>{{ text }}</p>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp } = Vue;

  createApp({
    data() {
      return {
        text: ""
      };
    }
  }).mount('#app');
</script>

</body>
</html>

관찰 포인트

  • input 값 변경 → 데이터 변경
  • 데이터 변경 → 화면 변경

3. 목록 렌더링 — v-for

v-for는 배열 데이터를 화면 목록으로 렌더링한다.

실습 5-3

파일명: 5-3-v-for.html

<!DOCTYPE html>
<html>
<body>

<div id="app">
  <ul>
    <li v-for="item in items">{{ item }}</li>
  </ul>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp } = Vue;

  createApp({
    data() {
      return {
        items: ["사과", "바나나", "포도"]
      };
    }
  }).mount('#app');
</script>

</body>
</html>

핵심 포인트

  • 배열이 화면 구조를 결정한다
  • DOM 생성/삭제를 직접 하지 않는다

4. Todo 예제 실습 (종합)

Vue의 핵심 개념을 하나의 예제로 묶는다.

실습 5-4

파일명: 5-4-todo.html

<!DOCTYPE html>
<html>
<body>

<div id="app">
  <input v-model="newTodo">
  <button @click="addTodo">추가</button>

  <ul>
    <li v-for="todo in todos">{{ todo }}</li>
  </ul>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp } = Vue;

  createApp({
    data() {
      return {
        newTodo: "",
        todos: []
      };
    },
    methods: {
      addTodo() {
        if (this.newTodo === "") return;
        this.todos.push(this.newTodo);
        this.newTodo = "";
      }
    }
  }).mount('#app');
</script>

</body>
</html>

실행 흐름

  1. 입력 → newTodo 변경
  2. 버튼 클릭 → addTodo() 실행
  3. 배열(todos) 변경
  4. 화면 자동 갱신

5. JavaScript 방식과 Vue 방식 비교

JavaScript (DOM 직접 제어)

todoList.appendChild(li);
  • DOM 생성/삭제 직접 처리
  • 데이터와 화면 코드 혼합

Vue 방식

<li v-for="todo in todos">{{ todo }}</li>
  • 상태만 변경
  • DOM 관리는 Vue가 담당

상태 변경 → Vue가 DOM 갱신 → 화면 반영

  • DOM 관리는 프레임워크가 대신한다

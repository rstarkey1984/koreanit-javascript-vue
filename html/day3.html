1. DOM(Document Object Model)

DOM은 브라우저가 HTML을 해석해 만든 문서 객체 구조다.
  • 브라우저는 HTML을 그대로 화면에 그리지 않는다
  • HTML을 해석해 DOM 객체 트리를 만든 뒤
  • 이 DOM을 기준으로 화면을 그린다

JavaScript는 DOM 객체를 통해서만 화면에 접근할 수 있다.

2. DOM 기본 확인

실습 3-1

파일명: 3-1-dom-basic.html

<!DOCTYPE html>
<html>
<body>

<h1>DOM 테스트</h1>
<p>이 문장은 DOM 요소다</p>

<script>
  console.log(document);
  console.log(document.body);
</script>

</body>
</html>

핵심 포인트

  • document는 브라우저가 제공하는 객체
  • document.body는 <body> 태그에 해당하는 DOM 객체

3. HTML 요소 선택

DOM 조작의 첫 단계는 원하는 요소를 정확히 찾는 것이다.

실습 3-2

파일명: 3-2-dom-select.html

<!DOCTYPE html>
<html>
<body>

<h1 id="title">제목</h1>
<p class="item">첫 번째</p>
<p class="item">두 번째</p>

<script>
  const title = document.getElementById("title");
  const item = document.querySelector(".item");

  console.log(title);
  console.log(item);
</script>

</body>
</html>

핵심 포인트

  • getElementById → id로 하나 선택
  • querySelector → CSS 선택자 방식

4. DOM 내용과 스타일 변경

DOM 객체의 값을 바꾸면 화면에 바로 반영된다.

실습 3-3

파일명: 3-3-dom-change.html

<!DOCTYPE html>
<html>
<body>

<h1 id="title">변경 전</h1>

<script>
  const title = document.getElementById("title");

  title.textContent = "변경 후";
  title.style.color = "red";
</script>

</body>
</html>

핵심 포인트

  • textContent → 텍스트 변경
  • style → CSS 속성 제어
  • DOM 변경 = 화면 반영

5. 이벤트와 DOM 연결

JavaScript는 이벤트가 발생했을 때 DOM을 변경한다.

실습 3-4

파일명: 3-4-event-dom.html

<!DOCTYPE html>
<html>
<body>

<h1 id="title">대기 중</h1>
<button id="btn">클릭</button>

<script>
  const title = document.getElementById("title");
  const button = document.getElementById("btn");

  button.addEventListener("click", function () {
    title.textContent = "클릭됨";
    title.style.color = "blue";
  });
</script>

</body>
</html>

핵심 포인트

  • 이벤트가 발생해야 함수가 실행된다
  • 함수 안에서 DOM을 변경한다

6. UI 실행 흐름 완성

지금까지 배운 내용을 하나의 흐름으로 묶는다.

실습 3-5

파일명: 3-5-ui-flow.html

<!DOCTYPE html>
<html>
<body>

<p id="count">0</p>
<button id="btn">증가</button>

<script>
  const countEl = document.getElementById("count");
  const button = document.getElementById("btn");
  let count = 0;

  button.addEventListener("click", function () {
    count = count + 1;
    countEl.textContent = count;
  });
</script>

</body>
</html>

이 코드의 실행 흐름

  1. 사용자가 버튼을 클릭한다
  2. click 이벤트 발생
  3. 함수 실행
  4. 데이터 변경
  5. DOM 변경
  6. 화면 반영

Day 3 실행 흐름 정리

이벤트 → 함수 → 데이터 변경 → DOM 변경 → 화면 반영

  • JavaScript는 DOM 객체를 조작해 UI를 바꾼다
  • 이벤트는 UI 변경의 출발점이다
  • DOM이 바뀌면 화면에 반영된다

1. 값과 변수 (Value & Variable)

JavaScript는 값을 만들고, 변수에 연결하고, 그 값을 사용하는 언어다.

이 장에서는 JavaScript에서 가장 중요한 개념인 값(Value) 과 변수(Variable) 를 구분해서 이해한다.

1-1. 값(Value)이란?

값은 JavaScript가 계산하고, 비교하고, 출력할 수 있는 실제 데이터다.

10
"안녕 JavaScript"
true

값은 다음과 같은 특징을 가진다.

  • 스스로 의미를 가진다
  • 연산의 대상이 된다
  • 화면에 출력될 수 있다

1-2. 값의 자료형(Type)

JavaScript에서 자료형(타입)은 변수가 아니라 값의 종류를 의미한다.

타입 설명 예시
number 숫자 10, 3.14
string 문자열 "hello"
boolean 참/거짓 true, false
null 의도적으로 비어 있는 값 null
undefined 아직 값이 없는 상태 undefined
object 여러 값을 묶은 타입 {}, []

JavaScript에서는 변수에 타입이 있는 것이 아니라, 값에 타입이 있다.

1-3. 변수(Variable)란?

변수는 값을 저장하는 공간이 아니라,
값을 가리키는 이름이다. 

let x = 10;

이 코드는 다음 의미를 가진다.

  1. x라는 이름을 만든다
  2. 숫자 값 10을 만든다
  3. 그 값을 x라는 이름에 연결한다

1-4. 변수와 값의 관계

JavaScript에서는 변수는 그대로이고, 값만 바뀔 수 있다.

let x = 10;
x = "10";

위 코드에서:

  • 변수 이름 x는 변하지 않는다
  • x가 가리키는 값만 변경된다

이것이 JavaScript에서

"변수의 타입이 바뀐다"라고 느껴지는 이유다.

1-5. 값 중심으로 코드 읽기

다음 코드를 변수가 아니라 값 기준으로 해석해보자.

let a = 10;
let b = a;
a = 20;

실행 흐름:

  1. 값 10 생성 → a가 가리킴
  2. b는 a가 가리키던 값 10을 가리킴
  3. a는 새 값 20을 가리킴

👉 b는 여전히 10을 가리킨다.

준비

  • 브라우저 개발자도구(Console)를 열어두고 진행한다
  • 각 단계마다 console.log() 결과가 예상과 같으면 다음으로 넘어간다

Step 1. 값 출력하기 (값은 그대로 ‘표현’할 수 있다)

  1. 아래 값들을 console.log()로 각각 출력한다.
  • 숫자: 10
  • 문자열: "10"
  • 불리언: true
  • null, undefined

체크 포인트

  • 10과 "10"의 출력 모양이 다르다
  • null과 undefined는 둘 다 “비어있음”처럼 보이지만 의미가 다르다

Step 2. 값의 타입 확인하기 (타입은 값에 붙는다)

  1. Step 1에서 출력한 값들에 대해 typeof 결과를 출력한다.

예)

typeof 10

체크 포인트

  • typeof 10 → "number"
  • typeof "10" → "string"
  • typeof true → "boolean"
  • typeof undefined → "undefined"

주의

  • typeof null은 결과가 직관적이지 않다(학생에게는 “예외”라고만 안내)

Step 3. 변수는 ‘이름’, 값은 바뀔 수 있다 (재할당)

  1. 변수 x를 만들고 숫자 값을 연결한다.
let x = 10;

  1. x + 5를 출력한다.

  2. 같은 변수 x에 문자열 값을 다시 연결한다.

x = "10";
  1. 이번에는 x + 5를 출력한다.

체크 포인트

  • 첫 번째는 숫자 덧셈 결과가 나온다
  • 두 번째는 문자열 연결 결과처럼 나온다

정리

  • “변수의 타입이 바뀐다”가 아니라
  • “변수가 가리키는 값이 바뀐다”

Step 4. 변수는 값 자체가 아니라 ‘가리키는 것’이다 (값 복사 감각)

  1. 아래 코드를 그대로 작성하고 각 줄마다 console.log(a, b)로 상태를 확인한다.
let a = 10;
let b = a;

a = 20;

체크 포인트

  • b는 여전히 10이다
  • a만 20으로 바뀐다

정리

  • b = a는 “a라는 상자를 통째로 b로 옮긴다”가 아니라
  • 그 시점의 값을 b에 연결하는 느낌으로 이해시키기

Step 5. 출력 예시를 ‘문장’으로 만들기 (코드 읽기 훈련)

  1. 아래처럼 출력 메시지를 포함해서 console.log()를 작성한다.

예)

console.log("x는 지금:", x);
console.log("x + 5 결과:", x + 5);

체크 포인트

  • 학생이 콘솔 로그를 보고 “지금 값이 뭐고, 결과가 왜 저렇게 나왔는지” 설명할 수 있어야 한다

정리

  • 콘솔에 값이 직접 출력되는 걸 확인했다
  • 같은 변수라도 값에 따라 결과가 달라질 수 있다는 걸 봤다
  • 변수는 값 자체가 아니라 값을 가리킨다는 걸 코드로 확인했다

2. 연산자 (Operator)

연산자는 값을 계산하거나 비교해 새로운 값을 만들어낸다.

연산자는 결과로 또 다른 값을 만든다.
이 결과 값이 변수에 저장되거나, 제어문의 조건으로 사용된다.

산술 연산자

10 + 5
10 - 3
10 * 2
10 / 2

문자열과 숫자

"10" + 5   // "105"
10 + "5"   // "105"

비교 / 논리 연산자

10 > 5
10 === 10
true && false

Step 1. 산술 연산 결과 확인

  1. 아래 연산을 각각 출력한다.

  • 10 - 3
  • 10 * 2
  • 10 / 2

체크 포인트

  • 연산 결과는 항상 새로운 값이다

Step 2. 문자열 결합과 숫자 덧셈 구분

  1. 아래를 각각 출력한다.
  • "10" + 5
  • 10 + "5"
  • "10" + "5"
  • 10 + 5

체크 포인트

  • +는 숫자면 덧셈, 문자열이 섞이면 결합처럼 동작한다

Step 3. 비교 연산 결과는 true/false

  • 10 > 5
  • 10 < 5
  • 10 === 10
  • 10 !== 5

  • 비교 연산 결과는 항상 true 또는 false 값이다

Step 4. 논리 연산으로 조건 조합 맛보기

  1. 아래를 출력한다.
  • true && false
  • true || false
  • !true
  1. 비교 연산과 섞어서 출력한다.
  • (10 > 5) && (3 > 1)
  • (10 < 5) || (3 > 1)

체크 포인트

  • 논리 연산은 true/false를 조합해 또 다른 true/false를 만든다

Step 5. 연산 결과를 변수에 저장

  1. let result = 10 + 5; 처럼 결과를 변수에 저장해 출력한다.
  2. 문자열 결합 결과도 변수에 저장해 출력한다.

체크 포인트

  • “연산 → 결과 값 생성 → 변수에 연결” 흐름이 보이면 통과

정리

  • 숫자를 계산하면 숫자 결과가 나온다
  • 문자열이 섞이면 +가 계산이 아니라 이어붙이기로 동작한다
  • 비교 연산의 결과는 항상 true 또는 false다
  • 논리 연산은 true / false를 조합해서 또 다른 결과를 만든다

3. 제어문 (Control Flow)

제어문은 코드의 실행 흐름을 제어하는 문법이다.

연산자(특히 비교/논리)의 결과로 나온 true/false 값을 이용해
"어떤 코드를 실행할지", "몇 번 반복할지"를 결정한다.

조건문 (if)

let score = 80;

if (score >= 60) {
  console.log("합격");
}

반복문 (for)

for (let i = 0; i < 3; i++) {
  console.log(i);
}

준비

Step 1. if의 조건을 바꿔가며 실행 확인

  1. score를 80으로 두고 실행한다 → "합격"이 출력되어야 한다
  2. score를 50으로 바꾸고 실행한다 → 출력이 없어야 한다

체크 포인트

  • if 블록은 조건이 true일 때만 실행된다

Step 2. else 추가 (조건이 false일 때)

  1. 아래 형태로 else를 추가한다.
  • 합격이면 "합격"
  • 아니면 "불합격"
  1. score를 80, 50으로 바꿔가며 실행한다

체크 포인트

  • if/else는 둘 중 하나만 실행된다

Step 3. for 기본 반복 이해

  1. for (let i = 0; i < 5; i++)로 0~4 출력
  2. 조건을 i < 3으로 바꿔 0~2 출력

체크 포인트

  • 초기값, 조건, 증가식의 의미를 말로 설명할 수 있다

Step 4. for로 합계 구하기

  1. sum 변수를 0으로 시작한다
  2. for로 1부터 10까지 더한다
  3. 최종 합계를 출력한다

체크 포인트

  • 반복문이 “여러 번 실행”을 만든다는 감각이 생기면 통과

Step 5. for + 조건 (짝수만 출력)

  1. 1~20까지 반복한다
  2. if를 이용해 짝수만 출력한다

힌트

  • i % 2 === 0

체크 포인트

  • for(반복)과 if(선택)가 결합되는 흐름을 이해한다

정리

  • 조건이 true일 때만 코드가 실행된다는 걸 직접 확인했다
  • 같은 조건이라도 값이 바뀌면 결과가 달라진다는 걸 봤다
  • for문으로 같은 코드를 여러 번 실행할 수 있다는 걸 경험했다
  • 반복문 안에서 if로 필요한 경우만 골라 실행할 수 있다는 걸 알게 됐다

4. 객체(Object)

객체는 관련 있는 데이터를 하나로 묶는 구조다.

객체는 "한 사람", "하나의 상품", "하나의 게시글"처럼
의미 있는 대상을 표현할 때 사용한다.

const student = {
  name: "kim",
  age: 18,
  city: "daegu"
};

특징

  • {} 로 생성
  • key : value 구조
  • 하나의 의미 있는 대상을 표현

  • 객체 전체를 출력하고, 필요한 값만 꺼내서 사용해봤다
  • 객체 안의 값은 실행 중에도 바뀔 수 있다는 걸 확인했다
  • 기존에 없던 속성도 나중에 추가할 수 있다는 걸 알게 됐다

5. 배열(Array)

배열은 순서가 있는 데이터 목록이다.

배열은 점수 목록, 할 일 목록처럼
같은 성격의 데이터를 여러 개 묶어서 관리할 때 사용한다.

const scores = [80, 90, 100];

배열 + 반복문

for (let i = 0; i < scores.length; i++) {
  console.log(scores[i]);
}

체크 포인트

  • 배열도 하나의 값이며, 여러 값을 묶는다

Step 2. index로 접근하기

  1. 첫 번째 값(scores[0])을 출력한다
  2. 마지막 값을 출력해본다

체크 포인트

  • index는 0부터 시작한다

Step 3. length 확인

  1. scores.length를 출력한다
  2. length 값이 왜 필요한지 말로 설명해본다

체크 포인트

  • 데이터 개수가 바뀌어도 반복문이 유지된다

Step 4. for로 전체 출력

  1. for로 배열 전체 요소를 출력한다

체크 포인트

  • i가 index 역할을 한다

Step 5. 합계와 평균 구하기

  1. for로 합계를 구한다
  2. 평균을 구해 출력한다

체크 포인트

  • “반복 + 누적(sum)” 패턴을 이해한다

Step 6. 조건과 함께 사용 (80점 이상만 출력)

  1. for로 전체를 돌면서
  2. if로 80점 이상만 출력한다

체크 포인트

  • 배열 + for + if 조합이 실무의 기본 패턴이다

정리

  • 여러 값을 순서대로 묶어서 다뤄봤다
  • 배열은 0번부터 시작한다는 걸 직접 확인했다
  • 반복문을 이용해 배열의 모든 값을 하나씩 처리해봤다
  • 조건을 추가해서 필요한 값만 골라낼 수 있다는 걸 경험했다

6. 함수(Function)

함수는 동작(로직)을 묶은 실행 단위다.

함수는 "필요할 때 실행할 코드"를 미리 정의해두는 방식이다.

function add(a, b) {
  return a + b;
}

핵심 포인트

  • 함수는 정의만으로는 실행되지 않는다
  • () 가 실행 신호다

  </script>

준비

  • “정의(만들기)와 호출(실행하기)”를 반드시 구분한다

Step 1. 함수 정의와 호출 분리

  1. add(a, b) 함수를 정의한다
  2. 아직 호출하지 말고 파일을 새로고침해본다

체크 포인트

  • 정의만 했을 때는 아무 출력도 없다

Step 2. 호출해서 실행 확인

  1. console.log(add(3, 5))를 출력한다
  2. console.log(add(10, 20))도 출력한다

체크 포인트

  • 같은 함수로 다른 입력을 처리할 수 있다

Step 3. return의 의미

  1. return이 있는 경우 값을 돌려준다는 점을 확인한다
  2. return 없이 console.log()만 하는 함수도 만들어본다

체크 포인트

  • return은 함수의 “결과 값”이다

Step 4. 함수 안에서 제어문 사용

  1. isPass(score) 함수를 만든다
  2. score가 60 이상이면 true, 아니면 false를 return
  3. 여러 점수를 넣어 결과를 출력한다

체크 포인트

  • 함수는 “연산자 + 제어문”을 포함하는 큰 단위가 될 수 있다

Step 5. 반복과 함께 사용

  1. 배열 scores를 하나 만든다
  2. isPass()를 이용해 합격/불합격을 각각 출력한다

체크 포인트

  • 배열 + for + 함수 패턴을 경험한다

정리

  • 코드를 한 번에 실행하는 게 아니라, 필요할 때 실행하도록 묶을 수 있다는 걸 확인했다
  • 같은 함수를 여러 번 호출해서 다른 결과를 만들 수 있다는 걸 봤다
  • 함수가 값을 계산해서 결과를 돌려줄 수 있다(return) 는 걸 경험했다
  • 함수 안에서도 조건문과 반복문을 사용할 수 있다는 걸 알게 됐다

7. 데이터와 함수의 관계

JavaScript에서는 데이터와 그 데이터를 처리하는 함수가 함께 존재한다.

객체 안에 값(상태)과 함수(동작)를 함께 넣으면
"한 덩어리의 기능"으로 관리할 수 있다.

const counter = {
  value: 0,
  increase: function () {
    this.value = this.value + 1;
    console.log(this.value);
  }
};

  <h1>데이터 + 함수 실습</h1>

  <script>
    // Step별 실습 코드는 이 안에 작성한다
  </script>

</body>
</html>

준비

  • 객체 내부에서 this는 “이 객체 자신”이라는 점만 먼저 잡고 간다

Step 1. counter 객체 만들기

  1. value: 0을 가진 counter 객체를 만든다
  2. 객체 전체를 출력한다

체크 포인트

  • counter는 “데이터(value)를 가진 하나의 대상”이다

Step 2. increase 함수 추가

  1. increase 함수를 객체에 넣는다
  2. 함수 안에서 this.value = this.value + 1 수행
  3. 증가 후 값을 출력한다

체크 포인트

  • 객체 안의 함수는 그 객체의 데이터를 바꿀 수 있다

Step 3. 여러 번 호출해서 상태 변화 확인

  1. counter.increase()를 3번 호출한다
  2. 콘솔 출력이 1, 2, 3으로 증가하는지 확인한다

체크 포인트

  • 값이 유지되는 것을 “상태(state)”라고 부른다

Step 4. decrease 추가하기

  1. decrease 함수를 추가한다
  2. this.value를 1 감소
  3. increase와 섞어서 호출해본다

체크 포인트

  • 같은 데이터에 대해 여러 동작을 붙일 수 있다

Step 5. 조건 넣기 (0 아래로 내려가지 않게)

  1. decrease 안에서 if (this.value > 0) 조건을 걸어본다
  2. 0에서 decrease를 호출해도 음수가 되지 않는지 확인한다

체크 포인트

  • 데이터 + 함수 + 제어문이 함께 묶인 구조를 경험한다

정리

  • 객체 안에 데이터(value) 와 동작(함수) 를 함께 넣어봤다
  • 함수가 실행될 때 객체의 값이 실제로 바뀌는 걸 확인했다
  • 여러 번 호출해도 값이 유지되는 상태(state)를 경험했다
  • 조건을 추가해서 데이터가 이상한 값으로 가지 않게 제어해봤다

8. 이벤트(Event)

이벤트는 함수 실행의 출발점이다.

JavaScript 코드는 대부분
사용자가 클릭/입력 같은 행동을 했을 때 실행된다.

<button id="btn">클릭</button>

<script>
  const button = document.getElementById("btn");

  button.addEventListener("click", function () {
    console.log("버튼 클릭됨");
  });
</script>

실습 가이드

📄 파일명: 8-event.html

<!DOCTYPE html>

<head>
  <meta charset="UTF-8" />
  <title>Day 2 - 이벤트</title>
</head>
<body>

  <h1>이벤트 실습</h1>

  <button id="btnPlus">+</button>
  <button id="btnMinus">-</button>

  <script>
    // Step별 실습 코드는 이 안에 작성한다
  </script>

</body>
</html>

준비

  • 이벤트는 “지금 당장 실행”이 아니라 “나중에 실행 예약”이라는 관점을 잡는다

Step 1. 요소 선택 확인

  1. getElementById로 버튼 2개를 변수에 담는다
  2. console.log(변수)로 실제 요소가 잡혔는지 확인한다

체크 포인트

  • null이 나오면 id가 틀렸거나 script 위치 문제일 가능성이 크다

Step 2. 클릭 이벤트 연결

  1. btnPlus에 click 이벤트를 연결한다
  2. 클릭하면 콘솔에 "plus"가 찍히게 한다
  3. btnMinus도 동일하게 "minus" 출력

체크 포인트

  • 이벤트는 “발생했을 때 함수가 실행”된다

Step 3. counter 상태와 연결 (Day 7의 counter 재사용)

  1. let value = 0; 변수를 만든다
  2. plus 버튼 클릭 시 value를 1 증가하고 출력
  3. minus 버튼 클릭 시 value를 1 감소하고 출력

체크 포인트

  • 이벤트가 발생할 때마다 값(상태)이 바뀐다

Step 4. 화면에도 표시하기 (최소 DOM)

  1. <p id="view"></p>를 body에 추가한다
  2. 클릭할 때마다 view.textContent = value;로 화면에 표시한다

체크 포인트

  • 콘솔 출력뿐 아니라 화면(UI)도 바뀐다

Step 5. 조건 추가 (0 이하로 내려가지 않게)

  1. minus 클릭 시 if (value > 0)일 때만 감소
  2. 0일 때는 "더 이상 감소 불가"를 콘솔에 출력

체크 포인트

  • 이벤트 + 제어문 + 상태가 하나로 연결된다

정리

  • 클릭 같은 사용자 행동이 코드 실행의 시작점이 된다는 걸 확인했다
  • 이벤트가 발생할 때마다 함수가 실행된다는 걸 경험했다
  • 이벤트를 통해 값이 바뀌고, 그 결과가 화면에 반영되는 걸 봤다
  • 조건을 추가해서 잘못된 동작을 막을 수 있다는 것도 확인했다

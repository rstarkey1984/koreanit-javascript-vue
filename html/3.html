1. DOM(Document Object Model)

DOM은 브라우저가 HTML을 해석해 만든 문서 객체 구조다.

  • 브라우저는 HTML을 그대로 화면에 그리지 않는다
  • HTML을 해석해 DOM 객체 트리를 만든 뒤
  • 이 DOM을 기준으로 화면을 그린다

👉 JavaScript는 DOM 객체를 통해서만 화면에 접근할 수 있다.

2. DOM 기본 확인

실습 가이드

📄 파일명: 2-dom-basic.html

<!DOCTYPE html>
<html>
<body>

<h1>DOM 테스트</h1>
<p>이 문장은 DOM 요소다</p>

<script>
  console.log(document);
  console.log(document.body);
</script>

</body>
</html>

준비

  • 브라우저에서 파일을 연다
  • 개발자도구(F12) → Console 탭을 켜둔다

Step 1. document 출력해보기

  1. 새로고침(F5) 한다
  2. 콘솔에 document가 출력되는지 확인한다

체크 포인트

  • 객체 형태로 길게 출력되면 정상

Step 2. document.body 출력해보기

  1. 콘솔에 document.body가 출력되는지 확인한다
  2. 출력된 결과에서 <body>...</body> 형태가 보이는지 본다

체크 포인트

  • <body> 태그가 DOM 객체로 잡혔으면 성공

실습 정리

  • 브라우저 안에는 document라는 객체가 항상 존재한다
  • document.body는 화면의 <body> 영역을 가리킨다
  • JavaScript는 document를 통해서만 화면에 접근한다

3. HTML 요소 선택

DOM 조작의 첫 단계는 원하는 요소를 정확히 찾는 것이다.

실습 가이드

📄 파일명: 3-dom-select.html

<!DOCTYPE html>
<html>
<body>

<h1 id="title">제목</h1>
<p class="item">첫 번째</p>
<p class="item">두 번째</p>

<script>
  const title = document.getElementById("title");
  const item = document.querySelector(".item");

  console.log(title);
  console.log(item);
</script>

</body>
</html>

준비

  • 콘솔을 켜두고 진행한다
  • 출력이 null이면 id/class 오타를 먼저 의심한다

Step 1. id로 요소 선택

  1. getElementById("title")를 그대로 실행한다
  2. 콘솔에 title이 출력되는지 확인한다

체크 포인트

  • 콘솔에 <h1 id="title">... 형태가 보이면 성공

Step 2. CSS 선택자로 요소 선택

  1. querySelector(".item")를 그대로 실행한다
  2. 콘솔에 item이 출력되는지 확인한다

체크 포인트

  • 첫 번째 <p class="item">첫 번째</p>가 잡히면 성공

Step 3. 선택 실패 상황 확인(중요)

  1. 일부러 getElementById("titl")처럼 오타를 내본다
  2. 콘솔 결과가 null로 바뀌는지 확인한다
  3. 다시 원래대로 고쳐서 정상 출력으로 되돌린다

체크 포인트

  • null은 "선택 실패" 신호다

정리

  • DOM 조작의 시작은 요소를 변수에 담는 것이다
  • 콘솔에 태그가 보이면 선택에 성공한 상태다
  • null이면 오타 또는 script 위치 문제를 점검한다

4. DOM 내용과 스타일 변경

DOM 객체의 값을 바꾸면 화면에 바로 반영된다.

실습 가이드

📄 파일명: 4-dom-change.html

<!DOCTYPE html>
<html>
<body>

<h1 id="title">변경 전</h1>

<script>
  const title = document.getElementById("title");

  title.textContent = "변경 후";
  title.style.color = "red";
</script>

</body>
</html>

준비

  • 파일을 새로고침(F5)하며 결과를 확인한다

Step 1. 텍스트 변경

  1. title.textContent = "변경 후"; 실행
  2. 화면의 글자가 바뀌는지 확인

체크 포인트

  • "변경 전" → "변경 후"로 바뀌면 성공

Step 2. 스타일 변경

  1. title.style.color = "red"; 실행
  2. 글자 색이 바뀌는지 확인

체크 포인트

  • 글자 색이 빨간색으로 보이면 성공

Step 3. 값 바꿔보기(응용)

  1. "변경 후"를 다른 문장으로 바꿔본다
  2. "red"를 다른 색으로 바꿔본다(예: "blue")

체크 포인트

  • 새로고침 후에도 내가 바꾼 값대로 반영되면 성공

정리

  • DOM 객체의 값이 바뀌면 화면도 즉시 바뀐다
  • JavaScript 한 줄이 화면을 직접 바꾼다

5. 이벤트와 DOM 연결

JavaScript는 이벤트가 발생했을 때 DOM을 변경한다.

실습 가이드

📄 파일명: 5-event-dom.html

<!DOCTYPE html>
<html>
<body>

<h1 id="title">대기 중</h1>
<button id="btn">클릭</button>

<script>
  const title = document.getElementById("title");
  const button = document.getElementById("btn");

  button.addEventListener("click", function () {
    title.textContent = "클릭됨";
    title.style.color = "blue";
  });
</script>

</body>
</html>

준비

  • 이번 실습은 새로고침만 해서는 아무 변화가 없다
  • 반드시 버튼을 눌러야 실행된다

Step 1. 버튼 요소가 잡히는지 확인

  1. console.log(button)을 추가해서 출력한다
  2. 콘솔에 <button id="btn">...가 찍히는지 확인한다

체크 포인트

  • null이면 id 오타 또는 script 위치 문제

Step 2. 클릭 이벤트 연결 확인

  1. 버튼을 클릭한다
  2. 제목이 "클릭됨"으로 바뀌는지 확인한다

체크 포인트

  • 클릭할 때마다 같은 결과가 반복되면 성공

Step 3. 이벤트 안에서 값 바꿔보기

  1. "클릭됨"을 다른 문장으로 바꾼다
  2. 색도 다른 색으로 바꾼다

체크 포인트

  • 클릭했을 때만 화면이 바뀌면 성공

정리

  • 이벤트는 코드 실행의 출발점이다
  • 클릭 → 함수 실행 → DOM 변경 → 화면 변경 흐름이 만들어진다

6. UI 실행 흐름 완성

지금까지 배운 내용을 하나의 흐름으로 묶는다.

실습 가이드

📄 파일명: 6-ui-flow.html

<!DOCTYPE html>
<html>
<body>

<p id="count">0</p>
<button id="btn">증가</button>

<script>
  const countEl = document.getElementById("count");
  const button = document.getElementById("btn");
  let count = 0;

  button.addEventListener("click", function () {
    count = count + 1;
    countEl.textContent = count;
  });
</script>

</body>
</html>

준비

  • count는 숫자 데이터(상태)
  • countEl은 화면에 보이는 영역(DOM)

Step 1. 클릭하면 숫자가 바뀌는지 확인

  1. 버튼을 여러 번 클릭한다
  2. 숫자가 1씩 증가하는지 확인한다

체크 포인트

  • 0 → 1 → 2 → 3 … 으로 증가하면 성공

Step 2. 데이터와 화면의 연결 확인

  1. count = count + 1; 줄을 잠깐 주석 처리한다
  2. 클릭해도 화면이 안 바뀌는지 확인한다
  3. 주석을 풀어 다시 정상 동작으로 되돌린다

체크 포인트

  • 데이터가 안 바뀌면 화면도 바뀌지 않는다

Step 3. 화면 업데이트 줄 확인

  1. countEl.textContent = count; 줄을 잠깐 주석 처리한다
  2. 클릭하면 count는 바뀌지만 화면은 안 바뀌는지 확인한다
  3. 주석을 풀어 다시 정상 동작으로 되돌린다

체크 포인트

  • 데이터 변경과 화면 반영은 다른 단계다

정리

  • 사용자 행동이 이벤트를 만든다
  • 이벤트가 함수 실행을 시작한다
  • 함수가 데이터를 바꾸고
  • DOM을 통해 화면이 바뀐다

이벤트

→ 데이터 변경

  • 이벤트는 실행의 출발점이다
  • UI는 이벤트에 반응해서 동작한다

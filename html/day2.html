강의 목표

JavaScript 코드는 데이터를 만들고 → 함수를 통해 처리하고 → 이벤트로 실행된다.

이 날의 목적은 문법 암기가 아니라, JavaScript 코드가 어떤 구조와 흐름으로 동작하는지를 이해하는 것이다.

  • 객체와 배열로 데이터를 구조화할 수 있다
  • 함수의 역할을 설명할 수 있다
  • 이벤트가 코드 실행의 출발점임을 이해한다

1. 데이터 구조의 필요성

JavaScript에서 데이터가 흩어져 있으면 관리하기 어렵다.

let name = "kim";
let age = 18;
let city = "daegu";

위 코드만 보면 이 값들이 누구의 정보인지, 어떤 관계인지 알기 어렵다.

결론
관련 있는 데이터는 하나로 묶는 구조가 필요하다.

2. 객체(Object)

객체는 관련 있는 데이터를 하나로 묶는 구조다.

실습 2-1

파일명: 2-1-object.html

<!DOCTYPE html>
<html>
<body>

<script>
  const student = {
    name: "kim",
    age: 18,
    city: "daegu"
  };

  console.log(student);
  console.log(student.name);
  console.log(student["age"]);
</script>

</body>
</html>
핵심 포인트
  • 객체는 {} 로 만든다
  • key : value 형태로 데이터를 저장한다
  • 하나의 의미 있는 대상을 표현한다

3. 배열(Array)

배열은 순서가 있는 데이터 목록이다.

실습 2-2

파일명: 2-2-array.html

<!DOCTYPE html>
<html>
<body>

<script>
  const scores = [80, 90, 100];

  console.log(scores);
  console.log(scores[0]);
  console.log(scores.length);
</script>

</body>
</html>
핵심 포인트
  • 배열은 [] 로 만든다
  • index는 0부터 시작한다
  • 같은 성격의 데이터를 순서대로 관리한다

4. 함수(Function)

함수는 동작(로직)을 묶은 실행 단위다.

실습 2-3

파일명: 2-3-function.html

<!DOCTYPE html>
<html>
<body>

<script>
  function add(a, b) {
    return a + b;
  }

  console.log(add(3, 5));
  console.log(add(10, 20));
</script>

</body>
</html>
핵심 포인트
  • 함수는 실행되기 전까지 아무 일도 하지 않는다
  • () 는 실행 신호다

5. 데이터와 함수의 관계

JavaScript에서는 데이터와 그 데이터를 다루는 함수가 함께 묶이는 경우가 많다.

실습 2-4

파일명: 2-4-data-function.html

<!DOCTYPE html>
<html>
<body>

<script>
  const counter = {
    value: 0,
    increase: function () {
      this.value = this.value + 1;
      console.log(this.value);
    }
  };

  counter.increase();
  counter.increase();
  counter.increase();
</script>

</body>
</html>
핵심 포인트
  • 데이터(value)와 동작(increase)을 함께 관리한다
  • this 는 이 객체 자신을 의미한다

6. 이벤트(Event)

이벤트는 사용자 행동 또는 브라우저의 변화다.

JavaScript 코드는 대부분 이벤트가 발생했을 때 실행된다.

실습 2-5

파일명: 2-5-event.html

<!DOCTYPE html>
<html>
<body>

<button id="btn">클릭</button>

<script>
  const button = document.getElementById("btn");

  button.addEventListener("click", function () {
    console.log("버튼 클릭됨");
  });
</script>

</body>
</html>
핵심 포인트
  • 이벤트는 함수 실행의 출발점이다
  • JavaScript는 이벤트가 없으면 동작하지 않는다

  • 함수는 실행할 동작을 정의한다
  • 이벤트는 함수 실행의 시작점이다

JavaScript & Vue 강의안

강의 성격 요약

이 강의는 Vue를 깊게 다루는 강의가 아니라,

JavaScript를 구조적으로 다루는 능력을 기르는 강의이며

Vue는 프레임워크의 역할을 이해하기 위한 마지막 맛보기 단계로 사용한다.

이 강의의 목표는

프레임워크 없이도 JavaScript 코드의 실행 흐름과 데이터 흐름을 설명할 수 있는 개발자를 만드는 것이다.

JavaScript를 배우는 목적

JavaScript를 공부하는 목적은 다음 세 가지다.

  • 사용자의 행동에 반응하기 위해서
  • 서버와 데이터를 주고받기 위해서
  • 화면(UI)을 동적으로 제어하기 위해서

이 강의에서는 문법 암기나 프레임워크 사용법보다

코드가 어떤 순서로 실행되고, 데이터가 어떻게 흘러가는지를 이해하는 데 집중한다.

강의 개요

Day 1 (월 · 3시간)

실행환경과 JavaScript 실행 흐름 이해

코드를 배우기 전에, 코드가 어디에서 어떤 순서로 실행되는지를 이해한다.

학습 목표

  • JavaScript 코드가 브라우저에서 실행되는 구조를 이해한다.
  • HTML과 JavaScript의 실행 순서를 설명할 수 있다.
  • 개발자 도구(Console)를 이용해 실행 결과를 확인할 수 있다.

주요 내용

  • 브라우저와 JavaScript 실행 환경
  • <script> 태그의 실행 시점
  • Console 사용법
  • 값과 변수의 개념
  • 간단한 객체와 함수 호출 흐름

Day 2 (화 · 6시간)

JavaScript 데이터 구조 이해 (객체 · 함수 · 배열)

JavaScript는 데이터를 중심으로 동작하는 언어임을 이해한다.

학습 목표

  • 값과 변수의 차이를 설명할 수 있다.
  • 객체(Object)를 이용해 데이터를 구조화할 수 있다.
  • 함수와 데이터의 역할을 구분할 수 있다.
  • 객체, 함수, 배열의 관계를 설명할 수 있다.

주요 내용

  • 기본 자료형
  • 객체(Object)의 구조
  • 배열(Array)의 구조
  • 함수(Function)의 역할
  • 객체 안의 함수(메서드)
  • 데이터와 동작의 분리 개념

Day 3 (수 · 6시간)

JavaScript 이벤트와 DOM 기초

사용자의 행동을 JavaScript 코드 실행으로 연결한다.

학습 목표

  • 이벤트의 개념을 이해한다.
  • 사용자 행동이 함수 실행으로 이어지는 구조를 설명할 수 있다.
  • JavaScript로 화면(UI)을 변경할 수 있다.

주요 내용

  • 이벤트란 무엇인가
  • 클릭 / 입력 이벤트 처리
  • DOM(Document Object Model)의 개념
  • HTML 요소 선택
  • 텍스트 및 스타일 변경
  • 이벤트와 DOM 조작 연결

DOM 구조화와 클래스(Class)

복잡해지는 코드를 정리하기 위한 구조를 이해한다.

학습 목표

  • DOM 코드가 왜 지저분해지는지 설명할 수 있다.
  • 클래스의 필요성을 이해한다.
  • 이벤트와 DOM 조작 로직을 클래스 안으로 정리할 수 있다.

주요 내용

  • DOM 코드 중복 문제
  • 전역 변수의 문제점
  • 클래스(Class)의 개념
  • 생성자(constructor)
  • 메서드(method)
  • DOM / 이벤트 로직의 구조화

Day 5 (금 · 3시간)

Vue.js 맛보기 – 구조를 대신 관리하는 도구

프레임워크의 존재 이유를 이해한다.

학습 목표

  • 프레임워크가 왜 필요한지 설명할 수 있다.
  • Vue.js가 DOM과 이벤트를 어떻게 단순화하는지 이해한다.
  • JavaScript 직접 구현 방식과 Vue 방식의 차이를 비교할 수 있다.

주요 내용

  • 데이터와 동작의 구조를 설명할 수 있다.

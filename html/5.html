1. Vue CDN 시작

Vue는 CDN 방식으로도 바로 사용할 수 있다.

실습가이드

📄 파일명: 1-vue-start.html

<!DOCTYPE html>
<html>
<body>

<div id="app">
  <p>{{ message }}</p>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp } = Vue;

  createApp({
    data() {
      return {
        message: "Hello Vue"
      };
    }
  }).mount('#app');
</script>

</body>
</html>

Step 1. Vue 라이브러리 로드

Vue를 CDN으로 불러온다. 이 스크립트가 있어야 Vue 문법을 사용할 수 있다.

체크 포인트

  • Vue CDN 스크립트가 <script>로 포함되어 있는가
  • Vue 관련 에러가 콘솔에 출력되지 않는가

Step 2. Vue 앱 생성

createApp() 함수로 Vue 애플리케이션을 생성한다.

체크 포인트

  • Vue 전역 객체를 정상적으로 사용할 수 있는가
  • createApp() 호출이 한 번만 이루어졌는가

Step 3. 상태(data) 정의

data() 함수에서 화면에 사용할 상태 객체를 반환한다.

체크 포인트

  • data는 함수 형태인가
  • 객체를 return 하고 있는가

Step 4. 화면 출력 확인

{{ message }}를 통해 상태 값이 화면에 표시되는지 확인한다.

체크 포인트

  • 중괄호 표현식이 그대로 출력되지 않는가
  • 상태 값이 정상적으로 화면에 표시되는가

Step 5. Vue 적용 영역 지정

.mount('#app')으로 Vue가 동작할 HTML 영역을 지정한다.

체크 포인트

  • id="app" 요소가 HTML에 존재하는가
  • Vue 문법이 해당 영역 안에서만 동작하는가

실습 정리

  • Vue는 특정 영역(#app)에만 적용된다
  • data()에서 반환한 값이 화면과 연결된다
  • DOM을 직접 건드리지 않아도 화면이 출력된다

2. 데이터 바인딩 — v-model

v-model은 입력값과 데이터를 양방향으로 연결한다.

실습가이드

📄 파일명: 2-v-model.html

<!DOCTYPE html>
<html>
<body>

<div id="app">
  <input v-model="text">
  <p>{{ text }}</p>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp } = Vue;

  createApp({
    data() {
      return {
        text: ""
      };
    }
  }).mount('#app');
</script>

</body>
</html>

Step 1. 입력값을 담을 상태 준비

text라는 문자열 상태를 data에 선언한다.

체크 포인트

  • text가 data 객체 안에 존재하는가
  • 초기값이 문자열로 설정되어 있는가

Step 2. 입력 요소와 상태 연결

v-model="text"로 input 요소와 상태를 연결한다.

체크 포인트

  • v-model 속성이 정확히 작성되었는가
  • 바인딩 대상 이름이 data와 일치하는가

Step 3. 입력 시 데이터 변화 확인

입력창에 값을 입력하면 text 상태가 변경되는지 확인한다.

체크 포인트

  • 입력 시 콘솔 에러가 발생하지 않는가
  • 입력값이 즉시 반영되는가

Step 4. 화면 자동 반영 확인

상태 변경이 즉시 화면에 반영되는지 확인한다.

체크 포인트

  • 별도의 DOM 조작 코드가 없는가
  • 입력과 출력이 동시에 바뀌는가

실습 정리

  • 입력값과 데이터가 자동으로 연결된다
  • 이벤트 리스너를 직접 작성하지 않는다
  • 데이터만 바꿔도 화면이 갱신된다

3. 목록 렌더링 — v-for

v-for는 배열 데이터를 화면 목록으로 렌더링한다.

실습가이드

📄 파일명: 3-v-for.html

<!DOCTYPE html>
<html>
<body>

<div id="app">
  <ul>
    <li v-for="item in items">{{ item }}</li>
  </ul>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp } = Vue;

  createApp({
    data() {
      return {
        items: ["사과", "바나나", "포도"]
      };
    }
  }).mount('#app');
</script>

</body>
</html>

Step 1. 목록 데이터 준비

items 배열을 data에 선언한다.

체크 포인트

  • 배열 형태로 선언되어 있는가
  • 초기 데이터가 정상적으로 들어 있는가

Step 2. 반복 렌더링 설정

v-for를 사용해 배열을 순회한다.

체크 포인트

  • v-for 문법이 올바른가
  • 반복 대상이 배열인가

Step 3. 항목 출력 확인

배열 요소가 <li> 목록으로 출력되는지 확인한다.

체크 포인트

  • 배열 길이만큼 <li>가 생성되는가
  • 화면에 undefined가 출력되지 않는가

Step 4. 데이터 변경 실험

배열에 값을 추가했을 때 목록이 자동으로 갱신되는지 확인한다.

체크 포인트

  • 새 데이터가 즉시 화면에 추가되는가
  • 새로고침 없이도 반영되는가

실습 정리

  • 배열 데이터가 곧 화면 구조가 된다
  • 반복 DOM 생성 코드를 작성하지 않는다
  • 데이터 변경이 렌더링으로 이어진다

실습 정리

  • 배열 데이터가 곧 화면 구조가 된다
  • 반복 DOM 생성 코드를 작성하지 않는다
  • 데이터 변경이 렌더링으로 이어진다

4. Todo 예제 실습 (종합)

Vue의 핵심 개념을 하나의 예제로 묶는다.

실습가이드

📄 파일명: 4-todo.html

<!DOCTYPE html>
<html>
<body>

<div id="app">
  <input v-model="newTodo">
  <button @click="addTodo">추가</button>

  <ul>
    <li v-for="todo in todos">{{ todo }}</li>
  </ul>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp } = Vue;

  createApp({
    data() {
      return {
        newTodo: "",
        todos: []
      };
    },
    methods: {
      addTodo() {
        if (this.newTodo === "") return;
        this.todos.push(this.newTodo);
        this.newTodo = "";
      }
    }
  }).mount('#app');
</script>

</body>
</html>

Step 1. 상태 구조 이해

newTodo는 입력값 상태, todos는 목록 상태다.

체크 포인트

  • 두 상태가 data에 모두 선언되어 있는가
  • 타입이 각각 문자열 / 배열인가

Step 2. 이벤트 연결

버튼 클릭 시 addTodo 메서드가 실행된다.

체크 포인트

  • @click 문법이 올바른가
  • methods에 함수가 정의되어 있는가

Step 3. 데이터 변경 로직 확인

배열에 값이 추가되고 입력값이 초기화되는 흐름을 확인한다.

체크 포인트

  • 빈 값 입력 시 추가되지 않는가
  • 배열에 문자열이 정상 추가되는가

Step 4. 화면 자동 갱신 확인

DOM을 직접 다루지 않아도 화면이 갱신되는지 확인한다.

체크 포인트

  • DOM API를 직접 사용하지 않았는가
  • 배열 변경만으로 화면이 바뀌는가

실습 정리

  • 입력 → 상태 변경 → 화면 갱신 흐름을 이해한다
  • Vue는 상태 변화를 기준으로 동작한다
  • Todo 예제에 Vue 핵심 개념이 모두 포함된다

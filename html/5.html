실습 공통 규칙 (CDN + Composition API 기본 틀)

Day 5 실습 파일들은 모두 아래 구조를 공통으로 사용한다.

기본 틀 코드

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <title>Vue 실습</title>
</head>
<body>

  <div id="app">
    <!-- 화면(템플릿) 영역 -->
  </div>

  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
  <script>
    const { createApp, ref, computed } = Vue;

    createApp({
      setup() {
        // 상태(ref), 계산(computed), 함수(이벤트 로직)를 여기서 준비한다.

        return {
          // 템플릿에서 사용할 상태/함수를 return 한다.
        };
      }
    }).mount("#app");
  </script>

</body>
</html>

체크 포인트

  • #app 안쪽은 Vue가 화면을 관리한다
  • setup()에서 상태와 함수를 만들고 return 하면 템플릿에서 쓸 수 있다
  • 상태는 ref()로 만든다

1. Vue CDN 시작

Vue 앱이 어떻게 만들어지고 화면과 연결되는지 확인한다.

📄 파일명: 1-vue-start.html

실습 가이드 기본 틀 코드

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <title>Vue 시작 (Composition API)</title>
</head>
<body>

<div id="app">
  <p>{{ message }}</p>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp, ref } = Vue;

  createApp({
    setup() {
      // Step 1: message 상태 만들기

      return {
        // Step 2: 템플릿에서 쓸 값 반환
      };
    }
  }).mount("#app");
</script>

</body>
</html>

Step

Step 1. 상태 만들기

setup() 안에 아래 코드를 추가한다.

const message = ref("Hello Vue");

Step 2. 템플릿에 연결하기

return에 message를 추가한다.

return { message };

체크 포인트

  • 화면에 Hello Vue가 출력된다
  • DOM 조작 코드 없이 상태만으로 화면이 만들어진다

2. 데이터 바인딩 — v-model

v-model은 입력값과 상태를 양방향으로 연결한다.

📄 파일명: 2-v-model.html

실습 가이드 기본 틀 코드

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <title>v-model 실습</title>
</head>
<body>

<div id="app">
  <input v-model="text">
  <p>{{ text }}</p>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp, ref } = Vue;

  createApp({
    setup() {
      // Step 1: text 상태 만들기

      return {
        // Step 2: 템플릿에서 쓸 값 반환
      };
    }
  }).mount("#app");
</script>

</body>
</html>

Step 1. 상태 만들기

const text = ref("");

Step 2. 템플릿에 연결하기

return { text };

체크 포인트

  • input에 입력하면 p에도 똑같이 나온다
  • 이벤트 핸들러 없이도 입력 ↔ 상태 ↔ 출력이 연결된다

3. 목록 렌더링 — v-for

v-for는 배열 데이터를 화면 구조로 자동 렌더링한다.

📄 파일명: 3-v-for.html

실습 가이드 기본 틀 코드

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <title>v-for 실습</title>
</head>
<body>

<div id="app">
  <ul>
    <li v-for="item in items" :key="item">{{ item }}</li>
  </ul>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp, ref } = Vue;

  createApp({
    setup() {
      // Step 1: items 배열 상태 만들기

      return {
        // Step 2: 템플릿에서 쓸 값 반환
      };
    }
  }).mount("#app");
</script>

</body>
</html>

Step 1. 배열 상태 만들기

const items = ref(["사과", "바나나", "포도"]);

Step 2. 템플릿에 연결하기

return { items };

체크 포인트

  • 배열 값이 <li> 목록으로 자동 출력된다
  • DOM 생성 코드 없이 Vue가 화면 구조를 만들어준다

4. Todo 예제 실습 (종합)

입력, 이벤트, 상태, 목록 렌더링 흐름을 하나로 묶는다.

📄 파일명: 4-todo.html

실습 가이드 기본 틀 코드

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <title>Todo 실습</title>
</head>
<body>

<div id="app">
  <input v-model="newTodo">
  <button @click="addTodo">추가</button>

  <ul>
    <li v-for="(todo, index) in todos" :key="index">
      {{ todo }}
    </li>
  </ul>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
  const { createApp, ref } = Vue;

  createApp({
    setup() {
      // Step 1: newTodo, todos 상태 만들기

      // Step 2: addTodo 함수 만들기 (상태만 변경)

      return {
        // Step 3: 템플릿에서 쓸 값 반환
      };
    }
  }).mount("#app");
</script>

</body>
</html>

Step 1. 상태 만들기

const newTodo = ref("");
const todos = ref([]);

Step 2. 추가 함수 만들기

const addTodo = () => {
  if (newTodo.value === "") return;

  todos.value.push(newTodo.value);
  newTodo.value = "";
};

Step 3. 템플릿에 연결하기

return {
  newTodo,
  todos,
  addTodo
};

체크 포인트

  • 버튼 클릭 → 함수 실행 → 상태 변경
  • 상태 변경 → 화면 자동 갱신(v-for)
  • DOM 추가/삭제 코드는 없다

5일차 핵심 정리

  • Vue는 DOM을 직접 다루지 않는다

  • 화면은 상태(State)의 결과다

  • 이벤트는 화면을 바꾸는 게 아니라 상태만 바꾼다

  • v-model은 입력과 상태를 연결한다

  • v-for는 배열을 화면 구조로 만든다

  • 핵심은 문법이 아니라 UI 흐름 이해다

1. JavaScript는 어디에서 실행되는가

JavaScript는 브라우저나 Node.js 같은 JavaScript 실행 환경(JavaScript Runtime) 위에서 실행된다.

핵심
JavaScript는 단독으로 실행되지 않는다. 항상 실행 환경 위에서 동작한다.

2. 브라우저의 역할

브라우저는 HTML·CSS·JavaScript를 처리하는 실행 환경이다. 브라우저 내부는 다음과 같은 구성 요소로 나뉜다.

  • HTML 파서
    HTML 문서를 해석해 DOM(Document Object Model) 구조를 생성한다.
  • CSS 파서 + 렌더링 엔진
    스타일을 계산하고 화면을 그린다.
  • JavaScript 엔진
    JavaScript 코드를 실행한다.
브라우저는 화면을 그릴 때, HTML을 해석해 만들어 놓은 DOM 객체를 기준으로 화면을 그린다.

3. HTML · CSS · JavaScript 역할 정리

그림: HTML/CSS/JavaScript와 브라우저 처리 흐름
  • HTML
    집의 설계도 → 브라우저가 읽어 DOM이라는 집의 뼈대를 만든다.
  • DOM
    브라우저 메모리에 만들어진 웹페이지의 실제 구조 객체
  • CSS
    DOM 요소를 화면에 어떻게 그릴지 알려주는 규칙(색, 크기, 위치, 배치)
  • JavaScript
    DOM 구조와 상태 자체를 변경하는 역할

브라우저에는 개발자 도구(Developer Tools)가 있다.

  • 값 확인
  • 에러 확인

5. JavaScript가 하는 일 (DOM 조작)

JavaScript는 브라우저가 만들어 둔 DOM을 조작하여 웹페이지의 구조와 상태, 동작을 실행 중에 변경하는 언어다.

실습 1-2

파일명: 1-3-dom-manipulation.html

<!DOCTYPE html>
<html>
<body>

<h1>원래 화면</h1>

<script>
  document.body.style.background = "black";
  document.body.style.color = "lime";
  document.body.innerHTML = "<h2>JavaScript가 바꾼 화면</h2>";
</script>

</body>
</html>
핵심 포인트
  • JavaScript는 화면을 직접 그리지 않는다
  • DOM 객체의 값을 변경한다
  • DOM이 바뀌면 화면에 반영된다

6. JavaScript 실행 시점

브라우저는 HTML 문서를 위에서 아래로 순서대로 해석한다. <script> 태그를 만나면:

  1. HTML 해석을 잠시 멈춘다
  2. JavaScript 코드를 실행한다
  3. 실행이 끝나면 HTML 해석을 이어서 진행한다

실습 1-4

파일명: 1-4-script-order.html

<!DOCTYPE html>
<html>
<body>

<script>
  console.log(document.getElementById("title"));
</script>

<h1 id="title">제목</h1>

<script>
  console.log(document.getElementById("title"));
</script>

</body>
</html>
핵심 포인트
<script> 위치에 따라 실행 결과가 달라진다.

7. 값과 변수 (Value & Variable)

JavaScript는 값을 만들고, 변수에 저장하고, 그 값을 사용하는 언어다.

실습 1-5

파일명: 1-5-variable.html

<!DOCTYPE html>
<html>
<body>

<script>
  let x = 10;
  console.log(x + 5);

  x = "10";
  console.log(x + "5");
</script>

</body>
</html>
핵심 포인트
  • 변수는 그대로, 값이 바뀐다
  • 값의 타입에 따라 동작 결과가 달라진다

7-1. 값(Value)이란?

값은 JavaScript가 계산하고, 비교하고, 출력할 수 있는 실제 데이터다.

10
"안녕 JavaScript"
true

값의 자료형 (Type)

타입 설명 예시
number 숫자 10, 3.14
string 문자열 "hello"
boolean 참/거짓 true, false
null 의도적으로 비어 있는 값 null
undefined 아직 값이 없는 상태 undefined
object 여러 값을 묶은 타입 {}, [], function(){}
JavaScript에서는 변수에 타입이 있는 것이 아니라, 값에 타입이 있다.

7-2. JavaScript vs Java 변수 선언 비교

구분 JavaScript Java
변수 선언 키워드 var, let, const 타입 자체가 선언 키워드
타입 선언 없음 필수

JavaScript 관점에서 읽기

let x = 10;

의미: x라는 이름의 변수를 만들고, 거기에 값 10을 넣는다.

Java 관점에서 읽기

int x = 10;

의미: 정수(int) 타입 변수 x를 선언하고, 값 10으로 초기화한다.

Day 1 실행 흐름 정리

HTML 해석 → DOM 생성 → JavaScript 실행 → DOM 변경 → 화면 반영

오늘의 핵심 정리

  • JavaScript는 실행 환경 위에서 실행된다
  • 브라우저는 HTML을 해석해 DOM 객체를 만든다
  • 화면은 DOM을 기준으로 그려진다
  • JavaScript는 DOM 객체를 조작한다
  • DOM이 바뀌면 화면에 반영된다
  • <script> 위치에 따라 실행 시점이 달라진다
  • Console은 실행 흐름을 확인하는 도구다
